## Shiftory explanation

Command-line arguments move into a ripgrep-specific definition model, repeatable value-taking flags select their last supplied value, and positional names become internally consistent.

### Behavioral before to after

#### Use the last value of a repeated value-taking flag

**Before:** ArgMatches exposed clap singleton accessors, whose repeated-value lookup selected clap's singleton result.

**After:** The wrapper owns singleton access and derives it from all supplied values by taking the last value.

Consumers such as replacement, color, and encoding read through the wrapper's last-value semantics.

Evidence: `hunk_fc5af61e310d2fdbc8a02cf0`, `hunk_d73f4cb8b9bcb82b8fbc81a4`, `hunk_b77b180416759cf98054665b`, `hunk_f3f7f066eda3e7bfc029725c`, `hunk_ba59948581fa78294734d7e9`, `hunk_b21c2ea5639ec7f8d28dc209`

Confidence: **extracted**

### Structural and non-behavioral changes

#### Define each command-line argument through a local model

**Before:** The clap application was assembled as one inline chain using shared closures and clap settings.

**After:** RGArg and RGArgKind describe positional arguments, switches, and value-taking flags, while per-argument functions keep each definition with its help text.

The application is generated from ripgrep-owned argument descriptions that are then translated to clap.

Evidence: `hunk_965a294ee2c07b721fc81195`, `hunk_aee6c6d1308c258c84531642`, `hunk_72fb5416ef8551c2dbae1a4e`, `hunk_19fa7fe9bbe8e5d8781ec90d`, `hunk_e88d601a2db2e041eb38f1d7`

Confidence: **extracted**

#### Use normalized internal names for pattern and path positionals

**Before:** Argument consumption referred to PATTERN and PATH using uppercase identifiers.

**After:** Argument consumption refers to the model's lowercase pattern and path identifiers.

Path and pattern extraction now uses the identifiers emitted by the new argument model.

Evidence: `hunk_10e2a744cda3a97dffeb30bd`, `hunk_cf936fecec9fa140c238c1cc`, `hunk_b6825d55a3ca179e948f2a29`
